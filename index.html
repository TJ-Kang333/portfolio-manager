설정 가이드 (PC에서 1회만 진행)
STEP 1. sheets.new에서 새 스프레드시트 생성 → 이름을 「포트폴리오 백엔드」 등으로 변경
STEP 2. 메뉴에서 확장 프로그램 → Apps Script 클릭
STEP 3. 기존 코드 모두 지우고 아래 코드를 붙여넣기 → → Ctrl+S 저장
STEP 4. 우측 상단 「배포」 → 「새 배포」 → 톱니바퀴 ⚙ 아이콘 → 「웹 앱」 선택
STEP 5. 다음과 같이 설정:
• 다음 사용자로 실행: 나(본인 이메일)
• 액세스 권한이 있는 사용자: 나만
STEP 6. 「배포」 클릭 → 권한 검토 → Google 계정 선택 → "Advanced" → "Go to ... (unsafe)" → 허용
(본인 만든 스크립트라 안전합니다. Google이 검증 안 했다는 표시일 뿐)
STEP 7. 「웹 앱 URL」 복사 → 위 입력란에 붙여넣기 → 저장
STEP 8. ↑ Sheets에 저장 버튼으로 현재 데이터 업로드 → ✓ 표시 확인
✓ 다른 기기에서: 같은 HTML 파일을 열고 → Sheets 연동 → 같은 URL 입력 → ↻ Sheets에서 불러오기
팁: 여러 기기 사용 시
• 데이터를 수정한 뒤엔 자동으로 Sheets에 저장됩니다 (URL이 설정되어 있을 때)
• 다른 기기에서 작업 시작 전엔 항상 ↻ Sheets에서 불러오기 먼저 실행
• 두 기기에서 동시에 수정하면 나중에 저장한 쪽이 덮어씁니다 — 한 번에 한 기기에서만 사용 권장
• Apps Script 배포 URL은 비밀로 유지 (URL 아는 사람은 데이터 접근 가능)
• 사이드바 하단에 동기화 상태(↻ ✓ ✕)가 실시간으로 표시됩니다
